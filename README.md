# Paypoint Solutions

## Overview
Marketing site for Paypoint Solutions with Texas-focused POS and payment processing SEO pages, blog content, and search engine metadata.

## Run locally
- Install dependencies with pnpm.
- Start dev server and open the local URL shown in the terminal.

## SEO endpoints
- Sitemap: `/sitemap.xml`
- Robots: `/robots.txt`
- RSS: `/rss.xml`

## Local SEO checklist
- Google Business Profile notes: `docs/google-business-profile.md`

## Notes
Update `NEXT_PUBLIC_SITE_URL` in your environment if you deploy under a custom domain.
